## ✨ Características

- **🎨 Diseño Moderno:** UI limpia con efectos de fondo sutiles (Aurora Background) y patrón de rejilla técnica.
- **🌗 Modo Oscuro/Claro:** Detección automática de preferencia del sistema y botón de cambio manual persistente.
- **⚡ Rendimiento:** Construido con Vite para una carga instantánea.
- **📱 Totalmente Responsivo:** Se adapta perfectamente a móviles, tablets y escritorio.
- **✨ Animaciones:** Transiciones suaves y efectos de entrada usando **Framer Motion**.
- **🛠️ Stack Tipado:** Código robusto usando **TypeScript**.

## 🛠️ Tecnologías Usadas

Este proyecto fue construido utilizando las siguientes herramientas y librerías:

* **Core:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
* **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
* **Animaciones:** [Framer Motion](https://www.framer.com/motion/)
* **Iconos:** [React Icons](https://react-icons.github.io/react-icons/) & [Lucide React](https://lucide.dev/)
* **Despliegue:** GitHub Pages

## 🚀 Instalación y Uso Local

Si deseas clonar y correr este proyecto localmente, sigue estos pasos:

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/notcaarlo/portfolio.git](https://github.com/notcaarlo/portfolio.git)
    ```

2.  **Instalar dependencias:**
    ```bash
    cd portfolio
    npm install
    ```

3.  **Correr el servidor de desarrollo:**
    ```bash
    npm run dev
    ```

4.  Abrir `http://localhost:5173` en tu navegador.
